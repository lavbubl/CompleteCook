This engine is open source built from mostly from scratch code meant to rectify decomps having too much assets. 

Do keep in mind, as much as the inner workings of this engine aim to be more readable than Pizza Tower's, it's still not beginner friendly. You must have an understanding of Gamemaker and programming before diving into using Complete Cook.

# Improvements to the vanilla game

The purpose of this engine was to give eager fangame creators a much easier time creating their project, and improvements 

* Code refactored, cleaned up, and made much more readable. 
* Collision additions; Side platforms, slope platforms and improved moving platforms.
* Easier language implementation.
* Common creation codes (i.e. Enemy variable for spawning during the escape) converted to the "Variable Definitions" feature.

# Setup

1. Install the latest version of the [Gamemaker LTS2026](https://gamemaker.io/en/download) IDE and Runtime.
2. **Clone** or **Download ZIP** the repository.
   
   ```
   $ git clone git://github.com/turbulenz/turbulenz_engine.git
   ```
    <p><img style="height:400px" src="https://github.com/user-attachments/assets/dfcd43f4-63d2-4d53-a255-287394fe5685"/><p/>
3. Open CompleteCook.yyp, from there you are in full control of what you do with the engine.
